# Contributing to MERN Stack Interview Questions

Thank you for helping improve **Code with Jamshed** learning resources.

## Good contributions

- Fix an incorrect or outdated explanation with a reference to official docs.
- Improve a code example, including any necessary imports or safety note.
- Add a meaningful interview follow-up or real-world scenario.
- Fix broken navigation, typos or accessibility issues.

## How to contribute

1. Fork this repository and create a descriptive branch.
2. Update the relevant question in `README.md`.
3. Explain the reasoning and testing steps in your pull request.
4. Keep explanations in clear, simple Indian English.
5. Do not include secrets, real user data or copied copyrighted answer sets.

## Style guide

- Keep code examples concise and correct.
- Clearly mark pseudo-code or snippets that need surrounding setup.
- Differentiate production-safe practices from simplified demos.
- Use stable GitHub question anchors (`q001` through `q100`).
- Preserve the section index and do not duplicate question numbers.
